# Первые консольные программы на C#

Два учебных проекта для .NET 10. GettingStarted показывает вывод текста и переносы строк, GettingStarted2 — объявление и вывод переменных разных типов. Решения можно открыть в Visual Studio или запустить из терминала:

~~~sh
dotnet run --project GettingStarted
dotnet run --project GettingStarted2
~~~
